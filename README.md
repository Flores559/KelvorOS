# KelvorOS v2.4 — MemoryCore

MemoryCore adds persistent memory, command history, favorites, projects, and a searchable memory dashboard.

## Run
```bash
npm install
npm start
```

## Commands
- memory status
- remember Kelvor is my AI assistant
- search memory Kelvor
- recent commands
- projects
- favorites
- system health
- prepare stream
